# Release checklist

## Code and infrastructure

- [ ] `pnpm verify` passes on Windows and Linux.
- [ ] Chromium and Edge launch-path tests pass on the pilot laptop.
- [ ] Cloud service account has minimum required roles.
- [ ] Same-origin, cookies, rate/size/concurrency limits, headers, budget alerts, and log exclusions are verified.
- [ ] Health output records actual local/cloud mode and exact model configuration.

## Content and people

- [ ] Ten exact phrase videos exist outside Git and have verified SHA-256 hashes.
- [ ] Signer consent, compensation, and exact distribution/publicity scope are retained privately.
- [ ] Independent Deaf reviewer has approved the exact bytes, caption pairing, and presentation.
- [ ] Catalog is published by a human release authority and no asset is withdrawn.
- [ ] Three to five compensated Deaf-user tests meet the acceptance gates.

## Pilot and submission

- [ ] Setup invoice is paid and recurring terms are documented.
- [ ] Pilot staff training and escalation path are complete.
- [ ] Actual product, customer, revenue, expense, and AI-operation evidence is retained privately.
- [ ] README and demo state what is real, what is local-only, and what remains blocked.
- [ ] Public video is under three minutes and uses only authorized media.

Any unchecked content or human gate blocks an ASL or market-readiness claim; it does not justify a placeholder approval.
